# Quantum Animal Shogi Board Viewer (量子どうぶつしょうぎ盤面ビューア)

ブラウザ上で動作する「量子どうぶつしょうぎ（Quantum Animal Shogi）」の対局・観戦・検証用インタラクティブ盤面ビューアです。

## 主な機能
- **量子状態（重ね合わせ）の可視化**: 駒ごとの候補状態（C, G, E, L, H）をグリッド表示
- **正規ルール準拠**: ひよこの成駒（にわとり / H）、キャッチ勝利、トライ勝利（王手回避 & トライ判定）に完全対応
- **棋譜再現・再生**: 1手指すごとの局面・候補集合の変化をステップ再生可能
- **共有用URL生成**: 盤面状態や棋譜をワンクリックでURL化して共有
